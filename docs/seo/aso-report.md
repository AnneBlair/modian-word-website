## 一、字段规则回顾

| 字段 | 上限 | 权重 | 是否对用户可见 |
|---|---|---|---|
| App 名称 | 30 字符 | **最高** | 可见 |
| 副标题 | 30 字符 | **次高** | 可见 |
| 关键词字段 | 100 字符 | 中 | 不可见 |
| 描述正文 | 4000 字符 | **不参与关键词索引**（App Store 与 Google Play 不同） | 可见 |
| 促销文本 | 170 字符 | 不索引 | 可见，可随时更新无需审核 |
| 更新日志 | 4000 字符 | 不索引 | 可见 |

**三条容易踩的规则**：

1. **关键词字段用英文逗号分隔，逗号后不要加空格**——空格会占用字符额度。
2. **同一个词在名称、副标题、关键词字段中只需出现一次**，Apple 只计一次。重复 = 浪费额度。
3. **关键词会自动组合**。若名称含「离线」、关键词含「词典」，则「离线词典」这个组合词也能被索引，不必单独写。

## 二、现状诊断

### 2.1 当前 App 名称的问题

```
墨典单词 - 高效学英语锁屏背单词的必备神器          （22 / 30 字符）
```

| 问题 | 说明 |
|---|---|
| **「必备神器」浪费 4 个字符** | 零搜索量的营销词。App Store 中文区大量应用用这类后缀，它既不带来搜索，也稀释了品牌观感 |
| **「高效学英语」过于宽泛** | 「学英语」是超高竞争词，一个独立应用不可能在这个词上排上去；等于用 5 个字符换零收益 |
| **完全没有「离线」** | 这是本产品**最锋利的差异化**（见 `keyword-research.md`），却没有出现在权重最高的字段里 |
| **「锁屏背单词」存疑** | 这是一个有独立搜索量、竞争极低的好词——**但官网上完全没有任何锁屏相关功能的描述**。需要确认该功能是否仍存在（见下） |
| 副标题状态未知 | 若未填写，等于浪费了权重第二高的 30 字符 |

### 2.2 需要产品方确认的三件事

| 待确认 | 为什么重要 |
|---|---|
| **锁屏 / 小组件功能是否仍存在？** | 若存在：这是极佳的差异化关键词，应保留在名称中，并**在官网补上对应功能说明**（当前官网完全没提，属于内容缺口）。若不存在：**必须从 App 名称中移除**——名称承诺了不存在的功能，是差评的直接来源，也可能触发 App Store 审核问题 |
| **副标题字段当前填了什么？** | 决定改动幅度 |
| **真实评分与评分数** | 用于官网 `AggregateRating` 结构化数据（见 `schema.md`），可显著提升搜索结果点击率 |


**用法**：这个字段不参与关键词索引，但它出现在描述最上方，是**唯一可以随时更新而不需要提审的可见文案**。适合放限时优惠、新版本亮点。

### 3.5 描述正文结构

App Store 的描述**不参与关键词索引**，所以它的唯一任务是**转化**，不是塞关键词。建议结构：

```
【前 3 行】（折叠前可见，最关键）
在你忘记之前，把单词复习一遍。
墨典单词按艾宾浩斯遗忘曲线安排复习，无广告、一次买断。
核心功能与英语词典均可离线使用。

【它解决什么问题】3–4 行
【核心功能】6–8 条，每条一行，动词开头
【适合谁 / 不适合谁】← 减少错配用户，直接降低差评率
【关于价格】一次买断，无内购，无订阅
【联系方式】
```

「不适合谁」这一节在中文 App Store 很少见，但它是**降低一星评价最有效的手段**——绝大多数一星差评来自预期错配，而不是产品缺陷。

## 四、美国区（en-US）

### 4.1 战略判断：窄而准，不要广撒网

这是本报告最重要的一个判断。

**墨典单词的单词释义是中文。** 如果在美国区用 `vocabulary builder`、`learn english`、`flashcards` 这类大词竞争，即使拿到下载，用户打开后发现释义是中文——**结果是一星差评**。而评分下降会同时伤害中国区的排名，因为评分是全球性的。

**正确策略**：把美国区定位为「服务在美的中文母语英语学习者」——留学生、华人社区、准备 GRE/TOEFL 的中国学生。这是一个真实存在且规模不小的人群，且竞争远低于泛英语学习。

### 4.2 推荐字段

**App 名称（28 / 30 字符）**
```
Modian Words - Chinese Vocab
```
- `Chinese` 一词同时起到**定位**与**筛选**作用：吸引目标人群，劝退不匹配用户
- 备选（若希望更突出离线）：`Modian Words: Offline Vocab`（27 字符）

**副标题（29 / 30 字符）**
```
Spaced repetition for CET/GRE
```
- `CET` 精准锁定中国考试人群
- 备选：`Ebbinghaus review, offline`（26 字符）

**关键词字段（96 / 100 字符）**
```
memorize,english,dictionary,offline,flashcard,ebbinghaus,IELTS,TOEFL,exam,learner,builder,recall
```

**跨语言额外额度**：美国区通常同时索引 **Spanish (Mexico)** 的关键词字段。若不做西语本地化，可把这 100 字符当作**第二个英文关键词槽**使用：
```
vocab,words,study,review,spelling,dictation,phonetic,notebook,mandarin,student,abroad,curve,interval,repetition
```
> 同样属于业内观察而非 Apple 官方文档，建议填了观察数据再判断。

### 4.3 美国区截图

**必须做的一件事**：截图里出现的界面**会展示中文释义**。与其掩饰，不如在第一张截图的文案里直说：

```
Definitions in Chinese — built for Chinese speakers learning English
```

这会降低点击转化率，但会**大幅提升安装后的留存与评分**。对一个靠评分吃饭的独立应用，这个交换是划算的。

## 五、日本区（ja-JP）

### 5.1 战略判断：**建议暂不投入**

诚实的结论：**在完成日语本地化之前，日本区不值得做 ASO 投入。**

理由：

1. 产品的单词释义是**中文**。日本用户看不懂，安装即卸载，且大概率留差评。
2. 日本英语学习 App 市场竞争激烈（mikan、iKnow!、abceed、英単語アプリ），且用户对本地化质量要求极高。半吊子的日语元数据 + 中文界面，在日本市场是明确的负面信号。
3. 日本用户对「英検」「TOEIC」「大学受験」这三套体系的词库有强需求，而本产品**没有这些词库**。即使本地化了界面，词库不匹配仍然无解。

### 5.2 如果只想低成本占位

只做元数据本地化、不改产品，目标是承接**在日中文母语者**（留学生、工作者）：

**App 名称（15 / 30 字符）**
```
墨典単語: オフライン英単語帳
```

**副标题（14 / 30 字符）**
```
エビングハウス忘却曲線で復習
```

**关键词字段（85 / 100 字符）**
```
英単語,単語帳,暗記,英語学習,辞書,復習,間隔反復,発音,TOEIC,TOEFL,IELTS,中国語,語彙,テスト,リスニング,スペル,英検,大学受験,語学,単語アプリ
```

**并且必须在描述第一行写明**：
```
※ 本アプリの単語解説は中国語です。中国語話者向けの英単語学習アプリです。
```

> 不加这一句，日本区的差评几乎是必然的。**加了这一句，下载量会很低——但这正是正确的结果**：不匹配的下载对这个产品是负资产。

### 5.3 如果决定认真做日本市场

需要的投入（按顺序）：

1. 界面日语本地化
2. **日语释义词库**（这是最大的工作量，也是决定性的）
3. 英検 / TOEIC / 大学受験 词库
4. 日语截图与描述
5. 日本区评分引导

**预估**：这是一个产品级项目，不是 ASO 项目。除非有明确的市场判断支撑，否则建议把同等精力投入中国区的深耕。

## 六、评分与评价

### 6.1 评分引导

Apple 的规则与最佳实践：

- 必须使用 **`SKStoreReviewController`**（`requestReview`）。自建弹窗跳转 App Store 评分页违反 App Store 审核指南 1.1.7。
- 系统每 365 天最多展示 **3 次**，超出的调用会被静默忽略。
- **不能**用奖励换评分，**不能**先问「你喜欢吗」再分流（把差评导向反馈、好评导向评分）——这是明确违规的做法。

**触发时机建议**（按价值排序）：

| 时机 | 理由 |
|---|---|
| 用户**完成第 15 天复习节点**时 | 这是产品价值兑现的时刻——用户刚刚经历了一次完整的记忆巩固周期 |
| 累计学习**满 30 天**时 | 长期用户，满意度最高 |
| 完成**一整本词库**时 | 成就时刻 |

**不要在这些时刻弹**：刚安装时、刚付费后、答错一批词之后、复习任务积压时。

### 6.2 评价回复

App Store Connect 支持开发者回复评价，且**回复后用户会收到通知，可以修改评分**。这是被严重低估的 ASO 杠杆。

| 评价类型 | 回复策略 |
|---|---|
| **一星（功能误解）** | 最高优先级。直接给出解决方法 + 说明在哪个版本已改进 + 邀请邮件联系。这类评分最容易被改回来 |
| **一星（预期错配，如「怎么是中文释义」）** | 说明产品定位，并致歉浪费了对方时间。同时**回头修改对应地区的元数据**——同类差评重复出现说明元数据有问题 |
| **一星（真实 bug）** | 确认问题 + 给出修复时间 + 修复后再回复一次告知 |
| **四五星** | 简短真诚地感谢，不要模板化。可顺带提一句相关功能 |
| **功能请求** | 说明是否在计划中，诚实说「暂时不做」也比不回复好 |

**回复原则**：24–72 小时内回复；不辩解；不复制粘贴模板；用第一人称（独立开发者身份是优势，用它）。

### 6.3 版本更新日志

更新日志不索引关键词，但**老用户会读**，且影响是否更新。

**写法**：
```
✅ 好的写法
- 复习提醒现在会在你设定的时间准时到达，不再延迟
- 修复了 iPad 分屏下词典弹窗被遮挡的问题
- 听写测试新增了慢速播放

❌ 差的写法
- 优化体验，修复已知问题
```

具体的更新日志传递「这个开发者还在认真维护」的信号，对付费应用尤其重要。

**当前状态未知，建议制作。** App Store 的预览视频会自动播放，对转化率提升显著。

## 八、Apple Search Ads 与自然排名

### 8.1 关于 Apple Search Ads

即使不投放，也建议**注册 Apple Search Ads 账户并使用其关键词推荐工具**——它提供 Apple 自己的搜索热度数据（Search Popularity 0–100），是唯一权威的 App Store 关键词量级来源，免费。

若考虑投放：用最小预算（如每天 ¥50）跑 2 周「精确匹配」，目的不是获客，而是**验证哪些关键词真的有搜索量**，再把结果反哺到自然 ASO 的字段配置。

### 8.2 官网对 ASO 的作用

三条真实存在的链路：

1. **品牌搜索量**：官网带来的品牌认知会转化为 App Store 内的「墨典单词」搜索——**品牌词搜索量是 App Store 排名的正向信号**。
2. **Smart App Banner**：已在全站添加 `<meta name="apple-itunes-app" content="app-id=1373544809">`，Safari 访问者会看到顶部安装横幅。
3. **Apple Search / Spotlight**：Applebot 已在 robots.txt 显式放行，官网内容有机会进入 Apple 生态的搜索结果。
