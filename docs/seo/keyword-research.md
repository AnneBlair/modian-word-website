**更新日期**：2026-08-11
**适用范围**：Google（中文简体 / 英文）、Bing、百度、Apple Search、AI 搜索

> **方法说明**：本表的竞争度分级基于关键词的商业意图强度、头部结果的域名权重构成（是否被应用商店、百科、大型内容站占据）以及词的具体程度，属于**策略性分级**，不是某个第三方工具的实测数值。搜索量列标注的是量级判断（高/中/低）。上线后应以 Google Search Console 的真实 Query 数据校准本表——**GSC 的数据比任何工具的估算都准**。

## 0. 关键词战略总览

墨典单词是一个新站、独立开发、无外链基础。在这种起点下，**去抢「背单词软件」这类头部词是纯粹的浪费**——那里的前 10 名被墨墨背单词、百词斩、扇贝的官网与各大应用商店占满，它们的域名权重高出几个数量级。

正确的路线是三层递进：

| 层级 | 目标词类型 | 为什么能赢 | 站内承载 |
|---|---|---|---|
| **第 1 层（0–3 月）** | 信息型长尾 + 问题词 | 头部结果多为低质内容农场，用一篇诚实、有出处的长文即可超越 | 支柱长文、博客、术语表 |
| **第 2 层（3–6 月）** | 「离线」限定词族 | 竞品普遍依赖云同步，**离线是墨典少数能真正独占的语义位** | 首页、离线专文、FAQ 离线组 |
| **第 3 层（6 月+）** | 产品型 / 对比型词 | 需要前两层积累的主题权威与品牌搜索量做支撑 | 下载页、功能页 |

**一个后来补上的发现**：`锁屏背单词` 原本写在 App 名称里，官网却完全没提——等于把一个**竞争极低、意图明确、且已经写在最高权重 ASO 字段里**的词族白白浪费了。功能经确认存在后已补齐（首页功能卡 + 专门教程页 + FAQ + 结构化数据）。这类「产品有、官网没写」的缺口值得定期排查：**对照 App Store 描述逐条核对官网覆盖**，往往能捡到最便宜的关键词。

**核心判断**：「离线」是本产品最锋利的差异化关键词。墨墨背单词、扇贝、百词斩都是重云端产品，「离线背单词」这个语义位在中文搜索里长期空置。这是本站最应该先占住的位置。

## 七、需要避开的关键词

| 关键词 | 原因 |
|---|---|
| 免费背单词 app | 产品是付费买断，导入的流量必然跳出，且可能招致差评 |
| 破解版 / 免费下载 | 与品牌调性不符，且是低质流量 |
| AI 背单词 / AI 英语 | **产品定位明确不做 AI 聊天工具**，追这个词会造成预期错配 |
| 英语口语 / 口语陪练 | 产品不提供口语功能 |
| 安卓 背单词 | 无 Android 版本 |
| 网页版 背单词 | 无网页版 |
| 背单词 排行榜 / 打卡 | 产品刻意没有社交与打卡功能 |

**这一节和前面几节同样重要。** 把不匹配的用户导进来，代价是 App Store 上的一星评价，而评分对 ASO 的影响是长期的。
