# 竞争分析 · 墨典单词

**更新日期**：2026-08-11

> **方法与边界**：本次执行环境的网络出口受限，无法逐个抓取竞品官网做实测（页面速度、结构化数据、实际排名等）。本文基于对这些产品**长期公开可见的产品形态与内容策略**的分析，以及有限的公开检索结果。因此本文的定位是**策略判断与可借鉴模式**，不是竞品站点的技术审计报告。带 ⚠️ 的结论表示需要实地核实后再据以行动。

## 一、竞争格局：三个不同的战场

把这九个产品放在一起比较容易造成误判——它们其实处在三个不同的竞争层。

| 层 | 产品 | 与墨典单词的关系 |
|---|---|---|
| **直接竞品**（同品类、同人群） | 墨墨背单词、百词斩、不背单词、扇贝单词 | 正面竞争，但**它们都是云端 + 免费增值 + 社交化**，墨典的定位与之正交 |
| **邻接竞品**（功能重叠） | 欧路词典、Anki | 欧路是词典优先、墨典是记忆优先；Anki 是通用工具、墨典是开箱即用 |
| **权威内容站**（只在搜索层竞争） | Google Dictionary、Oxford、Cambridge | 不争夺用户，但**在信息型关键词上占据 SERP 头部** |

**核心判断**：墨典单词在产品层面**不应该也无法**与前四家正面竞争（它们有资本、有团队、有多年积累的用户基数）。它的机会在于**占住这些产品结构性放弃的位置**——离线、买断、无社交、无广告。这四点不是「我们也有」的功能，而是「它们的商业模式决定了它们不会做」的东西。

## 二、逐个分析

### 2.1 墨墨背单词（MaiMemo）

**产品定位**：记忆算法驱动的背单词工具，中国区最主流的付费背单词产品之一。

**SEO / 内容做得好的地方**：

1. **学术背书是最强的护城河**。其记忆模型相关论文发表于数据科学顶会 ACM SIGKDD（*A Stochastic Shortest Path Algorithm for Optimizing Spaced Repetition Scheduling*）。这带来的不只是可信度——**它带来了大量高质量的外链与被引用**（学术引用、技术博客、知乎讨论），是 SEO 上极难复制的资产。
2. **多渠道分发**：App Store、Microsoft Store、各安卓应用市场、模拟器站点、下载站……几乎所有能建立品牌词落地页的地方都覆盖了。这让「墨墨背单词」这个品牌词的 SERP 被自家与合作方内容占满。
3. **开放 API 与社区生态**：提供云词库 API，催生了大量第三方同步工具（如 Eudic → MaiMemo 同步器）。**这些 GitHub 项目和技术博客构成了持续的自然外链来源**——这是一个被严重低估的 SEO 策略。
4. **UGC 词库**：用户共享词库既是产品功能，也是长尾内容页。

**可以借鉴的**：

- ✅ **把方法论说透，而不只是罗列功能。** 墨典的做法（支柱长文讲清遗忘曲线的来龙去脉，包括常见误引）走的是同一条路，且**在诚实度上可以做得更好**——主动澄清「1/2/4/7/15 不是艾宾浩斯原文」这类内容，是墨墨也没做的差异化。
- ✅ 若日后有余力，**开放一个简单的词库导入格式**并写好文档，可能吸引开发者社区做工具，带来技术类外链。

**不要学的**：

- ❌ **不要学它的付费模式。** 墨墨的「记忆单词上限 + 购买词量」模式在用户中长期存在争议。墨典的一次买断是一个清晰的差异化定位，**不要为了变现效率牺牲它**——这是产品最容易被记住的特征之一。
- ❌ 不要试图在「背单词软件」这个头部词上正面竞争。⚠️ 该词的 SERP 由墨墨、百词斩及各应用市场占据，新站没有机会。

---

### 2.2 百词斩

**产品定位**：图片记忆法 + 强社交属性，用户基数极大。

**做得好的地方**：

1. **「图背单词」是一个自创的、可被搜索的概念**。他们把一种记忆方式包装成品牌化的方法论，用户会主动搜索这个词——**创造品类词是内容营销的最高级玩法**。
2. **社交与打卡机制制造了海量 UGC**：朋友圈打卡截图、小红书笔记、B 站视频。这些是免费的品牌曝光与外链。
3. 视频化内容布局（B 站、抖音）覆盖了年轻用户的搜索入口。

**可以借鉴的**：

- ✅ **给自己的方法起一个可搜索的名字。** 墨典可以考虑把「在遗忘之前复习」这个理念做成一个可传播的说法。但要克制——**只有在方法确实有独特之处时才值得命名**，否则会显得空洞。
- ✅ 关注非搜索引擎的搜索入口：小红书、B 站、知乎。对中文产品，**这些平台的搜索量级不亚于百度**。

**不要学的**：

- ❌ **不要学社交与打卡。** 墨典的核心用户价值恰恰是「没有这些」。打卡机制会带来使用时长，但也带来大量为打卡而打卡的无效学习。
- ❌ 不要学广告变现。免费 + 广告是与「无广告」定位直接冲突的路径。
- ❌ ⚠️ 图片记忆法对抽象词（GRE 那类）效果有限，其宣传常回避这一点。**墨典应该反其道而行**——公开讨论方法的边界，这本身就是差异化的内容（见 `blog-plan.md` #11、#71）。

---

### 2.3 不背单词

**产品定位**：真实语境例句 + 精致设计。

**做得好的地方**：

1. **产品名本身是一个反直觉的钩子**。「不背单词」四个字自带传播性和记忆点。
2. **例句来自真实语料（影视、新闻）**，这既是产品卖点，也是天然的内容素材库。
3. 设计品质高，在小红书 / 设计社区有自然传播。

**可以借鉴的**：

- ✅ **反直觉的表达方式有传播力。** 墨典官网的「你不是记性差，你只是复习得太晚」就是这个思路，效果不错，可以在博客标题上延续。
- ✅ **例句语境化的重要性**值得在内容中强调（`blog-plan.md` #52、#66 已规划）。

**不要学的**：

- ❌ 不要学它相对复杂的功能层级。墨典的克制是优势。

---

### 2.4 欧路词典（Eudic）

**产品定位**：词典优先，可扩展词库，工具属性强。

**做得好的地方**：

1. **离线词库是它的核心卖点之一** ——这是九家里唯一在「离线」语义位上与墨典有真实重叠的产品。⚠️ 需要核实它当前在「离线词典」相关词上的实际排名。
2. **可扩展的词库生态**（用户可导入 mdx 等格式）催生了大量第三方词库站与教程，带来持续外链。
3. 多平台覆盖（iOS / Android / Mac / Windows / 浏览器插件），品牌词覆盖面广。

**可以借鉴的**：

- ✅ **离线是可以作为主打卖点的**——欧路证明了这个市场需求真实存在。
- ✅ 生词本导出 / 导入的互操作性会带来技术类外链（社区已有 Eudic → MaiMemo 的同步工具，说明用户有跨工具流转需求）。

**关键差异化**：欧路是**查词工具**，墨典是**记忆工具**。这两者常被用户混为一谈——**这本身就是一个内容机会**（`blog-plan.md` #88「词典 App 和背单词 App 是两件事」）。写清楚这个区别，既服务读者，也顺带明确了自己的定位。

**不要学的**：

- ❌ 不要学功能的无限堆叠。欧路的功能广度是它多年积累的结果，对一个强调克制的产品是反面参照。

---

### 2.5 扇贝单词

**做得好的地方**：早期的「打卡返学费」增长机制、内容矩阵（扇贝新闻、扇贝阅读等多 App 布局）、公众号内容运营。

**可以借鉴的**：无强相关。

**不要学的**：

- ❌ **打卡返现类增长机制**已被证明会带来大量低质用户与后续的信任问题。
- ❌ 多 App 矩阵会稀释品牌，对独立开发者是资源灾难。

---

### 2.6 Anki

**产品定位**：开源、通用、高度可定制的间隔重复工具。

**做得好的地方**：

1. **文档即内容营销**。Anki 的官方手册极其详尽，覆盖了间隔重复的方方面面，**长期占据大量英文长尾词的搜索结果**。这是「文档站做 SEO」最成功的案例之一。
2. **社区共享牌组**形成海量长尾页面。
3. 算法透明（SM-2 及后续的 FSRS），吸引技术型用户深度讨论，带来高质量外链。

**可以借鉴的**：

- ✅ **这是九家里最值得学的一家**。Anki 证明了：**把方法论文档写透，本身就是最好的 SEO**。墨典的支柱长文 + 术语表走的正是这条路，应该继续加深。
- ✅ **算法透明度带来信任**。墨典目前只说「第 1、2、4、7、15 天」，可以考虑更详细地解释答错时的降级逻辑——这类内容对认真的学习者有吸引力，也是可被引用的知识。

**不要学的**：

- ❌ 不要学它的学习曲线。Anki 的强大伴随着极高的上手成本，而墨典的价值主张是开箱即用。**这恰恰是墨典对 Anki 的差异化**，值得写成对比内容（`blog-plan.md` #82）。
- ❌ 不要学它的界面。

---

### 2.7 Google Dictionary / Oxford / Cambridge

这三家不是产品竞品，但在**信息型关键词的 SERP 上**是绕不开的存在。

**它们占据的位置**：

- 单词释义类查询（`define X`、`X 是什么意思`）——**几乎不可能撼动，不要尝试**
- 部分学习方法类查询（Cambridge 与 Oxford 都有学习博客）

**可以借鉴的**：

1. **Oxford / Cambridge 的学习资源栏目**是「权威机构做内容营销」的标准范式：术语解释、学习指南、词汇表分级（如 Oxford 3000/5000）。**墨典的术语表就是这个模式的小型实现**。
2. **词汇分级的概念**（Oxford 3000 / 5000、CEFR 对应）是有搜索量的信息型内容，且与产品的词库功能天然相关。可作为选题（`blog-plan.md` #76 附近可扩展）。

**不要学的**：

- ❌ 不要试图做在线词典功能来抢这些词。产品的词典是**离线的、辅助背诵的**，把它做成网页词典既偏离定位，又在一个必输的战场上消耗资源。

## 四、给墨典单词的结论

### 4.1 要打的仗

| 战场 | 为什么能赢 |
|---|---|
| **「离线」语义位** | 除欧路外无人认真争夺，而欧路是词典不是记忆工具。这是唯一可能被墨典独占的高价值位置 |
| **「买断 / 无广告 / 无社交」** | 头部竞品的商业模式决定了它们**结构性地无法**主打这些。这不是功能差异，是模式差异，无法被抄袭 |
| **方法论深度内容** | 参照 Anki 的路径。中文互联网上关于遗忘曲线的内容质量普遍很低（大量把 1/2/4/7/15 错误归给艾宾浩斯），**做对了就是降维打击** |
| **诚实的边界说明** | 几乎无人做「产品不适合谁」「方法的局限在哪」。这类内容既建立信任，又在 AI 搜索中更容易被引用 |

### 4.2 不要打的仗

| 战场 | 原因 |
|---|---|
| 「背单词软件」等头部词 | ⚠️ SERP 被高权重域名占满，新站无胜算，投入产出比极低 |
| 单词释义类查询 | Oxford / Cambridge / Google 的地盘 |
| 多平台矩阵 | 独立开发者的资源不允许，且稀释品牌 |
| 社交 / 打卡 / 排行榜 | 与核心定位直接冲突 |
| 免费 + 广告变现 | 同上 |
| 泛英语学习（口语、课程） | 产品不做，追这些词只会带来错配用户与差评 |

### 4.3 具体可执行的差异化动作

1. **把「离线」贯穿全链路**：官网（✅ 已做）、App 名称（见 `aso-report.md` P0）、截图（需补一张飞行模式截图）、描述、更新日志。
2. **持续产出方法论内容**，特别是**纠偏型**选题——这是竞品内容质量最低、AI 搜索最容易引用的空白地带。
3. **公开算法逻辑**到合理程度，参照 Anki 的透明度。
4. **写清楚产品不适合谁**。这会减少下载量，但会提升评分——而评分是 ASO 的长期复利。
5. **争取技术社区的自然外链**：开放词库导入格式、写好文档。这是墨墨与 Anki 都验证过的路径，且对独立开发者成本最低。
